# MailBox - Gmail-Style Programming Class Project

This is a front-end email application inspired by the general layout of Gmail.

## Features
- Responsive Gmail-style interface
- Inbox message list
- Read/unread styling
- Open an email
- Back to inbox
- Star/unstar messages
- Search emails
- Compose message window
- Fake send confirmation
- Select-all checkbox
- Collapsible sidebar
- Responsive layout for smaller screens

## How to run
1. Unzip the project.
2. Open `index.html` in a browser.

For a better development setup, open the folder in VS Code and run it with the "Live Server" extension.

## Files
- `index.html` - page structure
- `style.css` - styling
- `script.js` - app behavior and sample data

## Important
This is a classroom demo. It does not connect to Gmail, Google accounts, or real email servers.
